Balinese Statues Object Detection

A deep learning initiative to preserve cultural heritage by automatically detecting and classifying eight categories of Balinese statues using YOLO architecture.

Overview & Problem Statement

Balinese statues possess rich cultural and mythological significance, categorized into distinct classes such as Dewa, Dewi, Mitologi, and Raksasa. However, manual identification requires domain expertise. This project aims to bridge that gap by developing a reliable computer vision model capable of identifying eight specific categories of these statues in real-time.

Innovative Methodology & Data Pipeline

One of the major bottlenecks in training robust object detection models is acquiring enough varied angle data. To solve this, we implemented a 3D-to-2D dataset construction pipeline.

  • 3d_rotation 3D Scanning: Utilized Polycam to create accurate 3D models of 240 physical statues, refining them and adding display bases using Blender.
  • auto_awesome_motion Data Expansion: Extracted multi-angle images from the 3D reconstructions, generating a massive dataset of approximately 14,280 unique 2D images.
  • rule Strict Annotation: Distributed labeling tasks among four team members using Roboflow. We implemented strict data range boundaries to ensure no class overlap during the manual annotation process.

Model Architecture & Results

We experimented with advanced object detection architectures, focusing primarily on YOLOv11 and YOLOv12 due to their balance of speed and accuracy. The models were trained and evaluated using Google Colab.

Training Performance (YOLOv12n)

0.965 mAP50
0.928 Precision

Challenges & Key Takeaways

Managing a multi-stage data pipeline required strict coordination. Setting up local CUDA environments and tracking hyperparameters taught me the realities of deep learning engineering beyond writing code. Furthermore, refining the dataset iteratively proved that data quality often trumps model complexity when aiming for high precision.
